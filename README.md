# CV Generator

### Live Demo
[acs-cv-generator-wine.vercel.app](https://acs-cv-generator-wine.vercel.app/)

## Project Description
Web App CV builder that allows users to create, preview, and export professional resumes directly in the browser. Provides input sections for personal info, experiences, educations, skills, and any additional info - generating a real time preview that can be downloaded as a PDF.

## Features
- Real Time Preview - See changes while inputting
- PDF Export - Download CV with single click
- Dynamic Sections - Add or remove info easily
- A4 Layout - Download uses proper layout/format
- Local Storage - Saves all work on page exit 
- Responsive - Works on all devices / screens

## Tech Stack
- React (Vite)
- TailwindCSS
- HTML5
- JavaScript

## Installation & Setup
**Clone the repository**
  ```bash
   git clone https://github.com/ac-gh-19/resumeApp.git
   cd resumeApp
  ```
**Install dependencies**
```bash
npm install
```
**Start development server**
```bash
npm run dev
```
**Open in browser**
```bash
http://localhost:5173
```

**Build for production**
```bash
npm run build
```

## What I learned
While doing this project, I gained a feel and understanding of working with React and TailwindCSS. I experienced the firsthand power of React's component-based architecture and the ease it provided with the creation of modular, reusable, and maintainable code. Pairing it with TailwindCSS made styling and creating components even more efficient and intuitive, reducing repetitive CSS and allowing me to primarily focus on functionality and design.

I especially appreciated how React allowed me to keep related logic, structure, and styling within a cohesive component, making development feel natural and organized compared to the traditional splitting of logic / styling / DOM which I struggled with. Overall, this project was a very enjoyable and informative introduction to React, giving me a sense of it's flexibility and potential in development.
